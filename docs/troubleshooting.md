# 排错：从你看到的结果开始

简体中文 · [English](troubleshooting.en.md) · [文档入口](index.md)

先保留当前主机、配置路径、原任务或 request ID，以及错误代码。不要为了“重来一次”先删 Lintel state；原记录往往正是核对结果的依据。

| 看到的情况 | 下一步 | 说明 |
| --- | --- | --- |
| 记录列表显示部分记录无法读取，或返回 `invalid_job_record` | 保留坏原件与原 ID，分别查询可读任务；提供错误 code | 不删除 jobs／plans 来重试；当前源码保留正常记录并有摘要分页；继续加载下一页，详情按 section 读取，旧下载版不具备此增强 |
| 登记现有环境时找不到文件或目录 | 核对完整配置路径与目录是否存在；修正保留的输入，可展开原始诊断 | 登记不创建目录；需要空白根时用“新建环境” |
| 最新指南中的认证／记录命令不存在 | 核对所选 CLI 和目标 runner 的版本与 `capabilities`／`describe` | 公开 App 0.1.1／CLI 0.1.0 不随 main 指南升级；见[版本与源码入口](start-here.md) |
| Keychain 显示锁定、拒绝访问或无法检查 | 先处理系统提示或访问条件，再刷新清单；不要删除整个 item | 只能批准清单中可处理的登录字段；未检查不等于不存在，见[认证清理](cleanup.md) |
| 本地登录已移除，但当前 Claude 仍有认证 | 查看所选来源复查与当前执行器状态，核对未选注入和其他入口，重新启动实际 Terminal／IDE／服务后再查 | 本地移除不清除既有进程环境，也不证明服务端撤销；原 ID 复查不会重执行 |
| 认证清理返回更新不确定或暂存材料待核对 | 保留原 ID，查询原任务并检查逐项来源／`retained_sensitive_material` | 不换 ID 重删，不把本地字段缺失当成所有步骤完成；见[清理结果](cleanup.md#看懂清理后的结果) |
| 网页只能展示，无法操作本机 | 源码试用改用 `npm run dev:synthetic`；真实环境使用原生 App | 普通前端与官网没有真实执行通道 |
| App 能用，但终端找不到 `lintel` | 选择独立 CLI 的完整路径，核对 `version --json`、`context --json` | App 安装不自动修改 PATH；见 [Agent CLI](agents.md) |
| 返回 `accepted` 或 `ok:true`，但结果不明确 | 用原 ID 查看 job，检查 status、steps、coverage | 请求接收、请求处理成功、任务完成分别表达 |
| SSH 断线、等待超时，或出现 `needs_reconciliation` | 回到原主机和原 state，查询原 ID；按结果另行决定恢复 | 不重新提交一份同样的破坏性动作；见[远程](remote.md) |
| 批准被拒绝、计划过期或目标已改变 | 重新读取目标，生成并审阅新计划 | 不复用旧 hash，也不跳过目标核对 |
| 已恢复的字段又冲突，或恢复被阻止 | 查看任务之后的修改，按当前值重新作决定 | 后续编辑应被保留；恢复只处理属于该操作的字段 |
| 工作包阅读很慢或容量预检不通过 | 核对当前 runner 限额、所选原件、可用临时磁盘；按准确范围缩小选择 | 每页阅读前需要完整解密核验全包。归档与原生 resume 限额分别维护；见[工作保全](operator-guide.md#work) |
| 浏览器清理停在等待后续确认 | 核对原 profile 与 operation，按浏览器指南完成真实重启和再次批准 | App 退出、关标签页与浏览器完整重启不能互相替代 |
| 改完设置，正在开的 Claude 没变化 | 查看读回结果，并从所选配置根打开新会话 | 配置修改不会替已有进程刷新环境 |
| 自定义保护项太多，或只想批量改其中几项 | 先筛选，再逐行选择；需要批量时明确进入“批量编辑” | 批量只提供共同适用动作，并计入当前结果之外的选择；见[保护方案](operator-guide.md#protect) |
| 个人默认的名称与实际选择的方案不一致 | 按“个人默认 · 方案名”和实际说明核对，不要只看槽位名 | 与内置意图不同的已保存方案按语义标注，仍须每次重新预览 |
| IPv6 或代理测试显示未测试、失败 | 查看具体主机、通道与回显目标；仅在明确选择后运行测试 | 未测试不能读成“已阻断”或“没有泄漏”；见[网络](network.md) |
| App 更新、远端安装或 browser host 不可用 | 核对发行配置、当前平台与 App 随包资源 | 源码支持、资源已打包、实例可运行分别核对 |

## 向维护者提供什么

提供版本或候选来源、操作系统／架构、App 或 CLI 入口、目标类型、复现步骤、原 ID 和错误代码。路径可脱敏，只保留有诊断价值的结构。会话、工作包、凭据、口令和完整 state 不直接附到公开 issue；优先制作合成例子。

更具体的机制见 [Core / CLI](core.md)；当前已核验的平台与候选范围见[当前状态](current-state.md)。
