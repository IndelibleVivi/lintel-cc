# 先认清这几个对象

简体中文 · [English](concepts.en.md) · [文档入口](index.md)

理解下面的区别，就能判断 Lintel 将在哪里做什么，也能在换窗口或断线后找回结果。

## 主机、配置根、项目目录与浏览器

**主机**决定执行地点与用户。本机是当前 Mac；SSH 工作空间对应远端主机及其登录用户。远端环境、计划和记录由那台主机持有。

**环境**指 Lintel 登记的 Claude Code 配置根。**项目 cwd**是启动 Claude 时所在的代码或工作目录。两者可以不同；换配置根不意味着搬动项目代码。

**浏览器 profile**在浏览器模块里单独选择和配对。App 的本机浏览器不会随着 SSH 目标切换而移到 VPS。配置目录分离也不自动建立账户、凭据或操作系统层面的隔离。

## 预览、计划、任务与结果

**预览**让你看实际范围。对于 core 的计划型任务，**冻结计划**记录准确目标、选中内容或字段变化，并返回 ID 与 hash。批准必须对应那份计划；目标或相关内容变化后，要重新预览。

**任务**是已提交操作的持久记录。core job 使用原 plan ID；`accepted` 表示已持久接收，`completed` 才表示任务达到自己的完成目标。阅读 steps、coverage 和错误信息，才能知道哪部分完成。

查询原任务不会重新执行破坏性动作，但可能持久记录中断核对结果。需要恢复时，另外预览恢复计划并批准。浏览器 operation、会话启动 request 与 App 更新 intent 各有自己的记录，不能互换 ID 或统一当作 core job 提交。

## 工作包、迁入与继续会话

**工作包**是加密的 `.age` 文件，保存选中原件。只归档会保留旧目录与登录，不创建新配置根；保全并准备新环境会增加新根与选定内容的迁入步骤。

工作包能够在没有源 inventory／job 的独立 state 中打开。跨机器携带时，文件传输由你明确选择的系统工具完成；SSH controller 不隐式传包。

**迁入**把明确选中的资料送到预览的落点，不覆盖同名内容。保存会话原文、阅读资料、整理交接稿、把原生会话 resume 起来，是不同的操作。原生 resume 有独立格式、版本和认证条件；当前具体范围查[当前状态](current-state.md)。

**观察、基线接受与恢复。** 脱敏语义快照用于比较变化；逐项接受当前值只形成比较基线，不产生可恢复的工作正文。配置恢复、残留备份恢复和工作迁入各自读取不同的来源，也各自需要预览与批准，不能用一个原 ID 代替另一类操作的恢复依据。

## 默认方案、普通与批量编辑

保护方案先形成按主机和环境隔离的草案。普通编辑在每行选择本字段动作；批量编辑只为全部选中项提供共同适用动作，筛选之外的选中项不会悄悄消失。个人默认只保存非秘密意图，若与内置配方不同，界面按实际启用、关闭或移除的字段标注，下一次应用仍重新读取目标并生成计划。

## 配置读回与实际外发

设置读回证明目标字段已经按计划处理；已有 Claude 进程不会因此自动重启。受控通道的观察说明经过该代理的连接，不能覆盖直接出站。主动 IPv4／IPv6 测试说明那一次、那条路径的出口。
