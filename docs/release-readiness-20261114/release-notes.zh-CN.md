# Lintel 0.2.0 Preview — 待批准发行说明

这是未公开候选的发行说明草稿。版本号不表示已经发布；正式资产、摘要和验收结论以本目录最终交接记录为准。当前公开下载仍为 App 0.1.1 Preview 与 CLI 0.1.0。

## 这一版解决什么

Lintel 帮助你选择 Claude Code 环境、管理外发设置、保全和阅读工作资料、精确处理旧登录、操作指定浏览器 profile 与远端主机，并从原任务继续查询或恢复。0.2.0 把近期完成的认证来源、Keychain、任务体验及双语界面改进整理为同一代 App/CLI 候选。

### 登录来源与精确清理

- 在同一份预览中查看已识别的文件、Keychain、设置／shell 声明和当前执行器注入来源；保存登录与共享声明有明确区别。
- macOS 只更新已确认原 Keychain item 的 Claude 登录字段，保留 MCP、plugin、未知资料及 item identity。不会为了清登录导出凭据备份。
- 默认 Claude 目录与显式目录选择保留各自凭据命名空间；独立安全存储目录发生跨环境或无法确认时，先拒绝并说明，避免悄悄选用另一处登录。
- 清理结果分别报告所选本地来源、当前执行器、其他上下文和服务端撤销。移除本地登录不代表已撤销 token，也不会清除一个已运行终端里的环境变量。

### 原任务与恢复

- 远端记录损坏时仍显示可读任务，并明确列出未能读回的原记录；不再把不完整列表显示为全部历史。
- 无法核对的 runner 安装原记录会阻止新的安装提交，避免在不确定状态上重复动作。
- 文件被替换成管道等异常对象时有限失败；设置已经发布但持久化确认失败时准确保留不确定状态。
- 已接收任务重复查询使用原 ID，不重新执行。升级前尚未执行且缺少新认证目录绑定的旧预览需要重新生成；原已接收任务继续按原记录查询。

### 更清楚的 App 与发行包

- 改善中英文、Day/Night、小窗口、完整标签、清理入口、归档结果和键盘焦点；错误与部分结果有可操作的下一步。
- App 与 CLI 的产品版本统一为 0.2.0；Preview 仍是发行渠道。包内保留独立项目许可和第三方 notice。
- 候选门禁同时检查架构、实际执行权限、完整内部校验和、资源、原生版本及最终 DMG 内容。
- 更新 HTTPS 上游代理与探测所用的 TLS 信任根和证书校验依赖，排除已撤销信任的证书链。

## 支持范围与安装选择

候选目标为 Apple Silicon macOS App/CLI，以及 Linux x86_64/aarch64 CLI。具体允许发布的平台必须以本轮最终原生报告为准；交叉编译不能代替目标机器运行。

自动更新尚未配置。使用手动下载与独立版本目录升级，保留原 Lintel state、工作归档、原任务 ID 和旧安装。浏览器伴随扩展仍采用现有 developer/temporary 安装路径；没有新增浏览器商店分发。

如批准发布的是 ad-hoc App Preview，必须明确说明没有 Developer ID 与 Apple 公证，macOS 可能阻止首次打开。用户核对来源后是否采用 Apple 的单 App 例外流程由用户决定；本产品不关闭 Gatekeeper、不自动移除隔离。面向普通用户的一般分发应先完成正式签名、公证与真实下载首装验收。

只对已选择、可识别的来源与能力报告结果。未知 provider/helper、其他进程、其他设备和服务端状态仍需独立确认。来源清单不运行 helper；另行选择的官方状态命令可能调用客户端配置的 helper，并可能重新生成凭据，随后会做最终本地读回。不扫描所有 Keychain 账户，不承诺“防封”或彻底解除服务端关联。

## 升级与遇到问题

先记下未完成任务的原 ID，关闭 App 前按原任务查询。新 CLI 解压到新的版本目录，按包内 README 校验并显式运行；不要覆盖正在使用的二进制。App 替换前退出旧进程并保留旧 App。安装或升级失败时保留 state 与归档，继续查原 ID，不通过删除任务记录或重复提交“修复”。旧程序的存在不代表它可以安全写入所有未来格式；回退后的新修改应先确认兼容范围。
