# Lintel documentation

[简体中文 (canonical)](index.md) · English · [Repository home](../README.en.md)

Chinese is the canonical product-documentation edition. The English entrance and eleven user/operator guides below are maintained for semantic parity: commands, platform status, defaults, privacy and recovery boundaries change together. The original Chinese files still own specifications, acceptance and current state. Translation/source changes do not establish candidate installation, formal release or website deployment.

Start with the [quickstart](quickstart.en.md): select synthetic originals in a disposable home, review/approve an archive-only plan, query the original task, then read the ciphertext package in independent state. It uses no personal login/browser data. The [operator guide](operator-guide.en.md) follows six App goals end to end; [Agent CLI](agents.en.md) serves terminal/automation users with existing operation authorization.
