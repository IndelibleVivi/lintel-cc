# Native App views

The two `native-home` JPEGs and `native-reader.zh-CN.jpg` are unedited, real
macOS WebKit window captures of the same local 0.1.0 Preview candidate,
extracted from its read-only DMG. The home captures show their actual interface
language; the reader capture is Chinese UI, including when an English layout
uses it. All displayed data belongs to the named
synthetic trial; no real account, credential, work content or private path is
shown. A system window-sharing indicator may be present in the title bar; it
is not part of Lintel’s interface.

The tested App source is `fcae6cb1efb50c6384a31ddce161bee6a39646e0`, captured
on macOS 26.5.2 arm64 on 2026-10-20. The source and tested behavior are recorded
separately in [current state](../../../docs/current-state.md); these images do
not imply Apple signing, public distribution or acceptance on other platforms.
See the finite [asset index](../asset-index.json). Raw QA, temporary roots,
passwords and task state stay outside the public asset set.

`native-archive-selection-crop.zh-CN.png` is an explicitly edited derivative
of the same candidate's actual archive-plan capture. It includes only the
frozen selected-file region and a visible `REAL macOS APP · SYNTHETIC DATA ·
CROPPED / EDITED` caption. The temporary configuration-root header is outside
the crop; the original capture stays private. No native text or control was
redrawn, translated or replaced. This detail proves only the shown selection,
not the complete target/approval dialog or a new execution.
