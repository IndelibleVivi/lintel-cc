# Native App views

The two `native-home` JPEGs are unedited, real macOS WebKit window captures of
the same local 0.1.0 Preview candidate, extracted from its read-only DMG. Each
shows its actual interface language. All displayed data belongs to the named
synthetic trial; no real account, credential, work content or private path is
shown. A system window-sharing indicator may be present in the title bar; it
is not part of Lintel’s interface.

The tested App source is `fcae6cb1efb50c6384a31ddce161bee6a39646e0`, captured
on macOS 26.5.2 arm64 on 2026-10-20. The source and tested behavior are recorded
separately in [current state](../../../docs/current-state.md); these images do
not imply Apple signing, public distribution or acceptance on other platforms.
See the finite [asset index](../asset-index.json). Raw QA, temporary roots,
passwords and task state stay outside the public asset set.
