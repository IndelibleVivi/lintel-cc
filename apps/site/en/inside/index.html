FOUR PATHS / CLEAR OWNERS

Four execution paths

Configuration readback, proxy observation, browser operations and App updates are not the same evidence.

  1. 01

    Environment and files

    The local core or target runner owns inventory, frozen plans, file operations and original tasks. The SSH controller sends finite requests but cannot declare remote completion.

    Core and CLI
  2. 02

    Browser

    The local Native Messaging host coordinates pairing; the paired extension owns profile-native operations. Cleanup requires a real restart and a second approval.

    Browser guide
  3. 03

    Network

    A channel constrains only connections routed through it. Configuration readback and actual egress tests are recorded separately. Direct sockets, UDP and DNS are outside that proof.

    Network guide
  4. 04

    App updates

    The native updater handles checks, signature verification, approved installation and explicit restart; its records are independent of core jobs. There is no public feed.

    Install and update

PLAN / APPROVAL / RESULT

How one operation retains its path

Generate and persist plan→Review exact scope→durable accepted→Execute→Check original task

Frozen plan

The exact target, selection or field changes bind a plan ID and hash. Changed conditions require another preview; approval is never reused.

Original task

accepted means only durable receipt; completed, partially completed, failed and needs-reconciliation remain distinct.

Independent work package

An encrypted package retains selected original bytes and can be read in independent state. Reading, import and native continuation are different operations.

NOT A MAGIC BUTTON

Design boundaries

Not
A generic cleaner, fingerprint spoof or account-unban tool.
No default
Uploads of work content, telemetry, accounts or a whole-machine environment inventory.
No inference
Configuration readback does not control all network traffic; a local directory boundary is not an account or OS sandbox.
No hiding
Unverified platforms, missing resources and unsupported syntax return specific limitations.

Hold the complexity. Leave a little room.
