What these terms mean

Source
The path exists in the repository; the exact revision under test is a separate fact.
Local candidate
A specifically built local package for trial or acceptance. It does not automatically receive public distribution authority.
Public bytes verified
Public URL bytes and SHA-256 match the original record. This still does not prove installation, authentication or Apple trust.
Released
Published with a checkable record. This page never infers this step from another fact.
