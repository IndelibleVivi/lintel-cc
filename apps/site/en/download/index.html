INSTALLATION BOUNDARY

Installation order and boundaries

  1. 01
    Verify the source first

    Record the candidate version, architecture, source revision and actual origin. The same version number does not identify the same build.

  2. 02
    Build locally when needed

    Use current source, locked dependencies and Xcode Command Line Tools. A build is not a formal release.

  3. 03
    Use synthetic material for the first trial

    Register an explicit test directory, complete an archive and read it again without first changing your personal Claude environment.

  4. 04
    Follow the system trust prompts

    A build without Developer ID/notarization is not a formal installer. Do not disable Gatekeeper globally or use xattr to bypass it.
