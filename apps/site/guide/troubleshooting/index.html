排错：从你看到的结果开始

简体中文 · English · 文档入口

先保留当前主机、配置路径、原任务或 request ID，以及错误代码。不要为了“重来一次”先删 Lintel state；原记录往往正是核对结果的依据。

看到的情况下一步说明
网页只能展示，无法操作本机源码试用改用 npm run dev:synthetic；真实环境使用原生 App普通前端与官网没有真实执行通道
App 能用，但终端找不到 lintel选择独立 CLI 的完整路径，核对 version --json、context --jsonApp 安装不自动修改 PATH；见 Agent CLI
返回 accepted 或 ok:true，但结果不明确用原 ID 查看 job，检查 status、steps、coverage请求接收、请求处理成功、任务完成分别表达
SSH 断线、等待超时，或出现 needs_reconciliation回到原主机和原 state，查询原 ID；按结果另行决定恢复不重新提交一份同样的破坏性动作；见远程
批准被拒绝、计划过期或目标已改变重新读取目标，生成并审阅新计划不复用旧 hash，也不跳过目标核对
已恢复的字段又冲突，或恢复被阻止查看任务之后的修改，按当前值重新作决定后续编辑应被保留；恢复只处理属于该操作的字段
工作包阅读很慢或容量预检不通过核对当前 runner 限额、所选原件、可用临时磁盘；按准确范围缩小选择每页阅读前需要完整解密核验全包。归档与原生 resume 限额分别维护；见工作保全
浏览器清理停在等待后续确认核对原 profile 与 operation，按浏览器指南完成真实重启和再次批准App 退出、关标签页与浏览器完整重启不能互相替代
改完设置，正在开的 Claude 没变化查看读回结果，并从所选配置根打开新会话配置修改不会替已有进程刷新环境
自定义保护项太多，或只想批量改其中几项先筛选，再逐行选择；需要批量时明确进入“批量编辑”批量只提供共同适用动作，并计入当前结果之外的选择；见保护方案
个人默认的名称与实际选择的方案不一致按“个人默认 · 方案名”和实际说明核对，不要只看槽位名与内置意图不同的已保存方案按语义标注，仍须每次重新预览
IPv6 或代理测试显示未测试、失败查看具体主机、通道与回显目标；仅在明确选择后运行测试未测试不能读成“已阻断”或“没有泄漏”；见网络
App 更新、远端安装或 browser host 不可用核对发行配置、当前平台与 App 随包资源源码支持、资源已打包、实例可运行分别核对

向维护者提供什么

提供版本或候选来源、操作系统／架构、App 或 CLI 入口、目标类型、复现步骤、原 ID 和错误代码。路径可脱敏，只保留有诊断价值的结构。会话、工作包、凭据、口令和完整 state 不直接附到公开 issue；优先制作合成例子。

更具体的机制见 Core / CLI；当前已核验的平台与候选范围见当前状态。
