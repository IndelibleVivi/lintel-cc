# Distribution notices

`frontend.md` contains Vite's generated frontend license and copyright texts.
`rust.md`, its inventory and accompanying runtime/license files contain the
target-filtered Rust normal/build dependency superset and toolchain notices.
This collection is not an exact linked SBOM and does not license Lintel's
original material.

Only this reading note is tracked here, so native development and tests work
from a clean checkout. `npm run desktop:build` builds the frontend, validates
all notice sources and generates the complete bundle before compiling the App.
The reading note alone is not a complete distribution.
