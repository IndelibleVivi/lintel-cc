# Licensing scope

This revision introduces forward-only project grants. It is a source-available Preview, not OSI open source. Earlier released artifacts are not repackaged or relicensed by this change; prior third-party grants remain intact.

| Material | Terms |
| --- | --- |
| Project-original functional code in crates/, apps/, extensions/, scripts/, tests/ and contracts/, including build scripts and examples | SUL-1.0, full text in [LICENSE](LICENSE) |
| Project-original Markdown documentation and independent original technical diagrams | CC BY-NC-SA 4.0, full text in [LICENSE-DOCUMENTATION](LICENSE-DOCUMENTATION) |
| Clawd character, brand names, wordmarks, logos, icons, screenshots, raster art, animation, audio, fonts and assets whose provenance/authority is not independently verified | Excluded from these grants; no additional permission is offered here |
| Third-party dependencies, incorporated material and notices | Their respective existing terms; retain third-party notices |

Exclusions take precedence over directory defaults, including brand/Clawd material embedded in code or documentation. This map grants only rights controlled by the offering rights holder; repository presence and commit authorship alone do not establish ownership. Unknown-source assets remain excluded pending rights verification. No trademark license is granted. Original authors retain copyright; no assignment is required.

Software terms: [official SPDX text](https://spdx.org/licenses/SUL-1.0.html)
Documentation legal code: [official Creative Commons text](https://creativecommons.org/licenses/by-nc-sa/4.0/legalcode.en)

The transition starts with the first revision containing this map and both license texts, after baseline b5349058a6c963f8c97eaa75d7c07e69b88c3cb3. It does not assert that previously unlicensed project-original releases carried these terms.
